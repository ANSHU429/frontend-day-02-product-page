# Day 02 — Auralis Studio One Product Page

A responsive fictional product showcase built with HTML, CSS, and vanilla JavaScript. It features a product image gallery, color selection, quantity controls, and shopping bag interactions.

## Technologies

- **HTML5** — page structure and product content (`index.html`)
- **CSS3** — responsive layout and visual styling (`product-page.css`)
- **JavaScript** — gallery, quantity, color, and bag interactions (`product-page.js`)

## Project files

- `index.html` — product page markup
- `product-page.css` — responsive styling
- `product-page.js` — interactive behavior

## Run locally

Open `index.html` in a browser. To serve it locally, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

This is a fictional brand and demo concept for portfolio practice. The content is designed to simulate an e-commerce landing page without a framework or backend.
