# Day 02 — Auralis Studio One Product Page

A clean and original product showcase built with HTML, CSS, and vanilla JavaScript. It focuses on polished layout, responsive design, and a few small interactive details that make the page feel complete.

## Project summary

This is a fictional product landing page for **Auralis Studio One**, a wireless headphone concept. The page includes:

- a hero-style product layout
- image gallery thumbnails
- color selection controls
- quantity selector and dynamic pricing
- shopping bag interaction
- expandable product details
- mobile-friendly responsive navigation

## Technologies used

- HTML5
- CSS3
- Vanilla JavaScript

## Files

- `index.html` — page structure and product content
- `styles.css` — responsive layout, design styling, and visual polish
- `script.js` — interactive gallery, quantity, color, and bag behavior

## How to run

Open `index.html` in a browser.

If you want to serve it locally with a simple dev server, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This is a fictional brand and demo concept for portfolio practice. The content is intentionally original and designed to simulate a real-world e-commerce landing page without depending on any framework or backend.
