# Auralis Studio One

A quieter moment, wherever the day takes you. This responsive product page introduces the fictional Studio One wireless headphones through a simple, editorial-style shopping experience.

## The experience

Visitors can browse product images, pick a color, change the quantity, and add headphones to their bag. The page also includes product details, shipping information, and a customer review.

## Built with

- **HTML** for the page structure
- **CSS** for the layout, styling, and responsive design
- **Vanilla JavaScript** for the gallery, color and quantity controls, and shopping bag feedback

## Project files

- `index.html` — product page content and structure
- `product-page.css` — responsive styles
- `product-page.js` — page interactions
- `styles.css` and `script.js` — duplicate stylesheet and script files retained in the repository

## Run locally

Open `index.html` in a browser, or start a local server from the project directory:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## About Auralis

Auralis is a fictional brand for a frontend practice project. The page is a visual demo; it does not connect to a real store or checkout.
