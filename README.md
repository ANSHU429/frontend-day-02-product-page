# Day 02 — Auralis Studio One Product Page

A responsive fictional e-commerce product page showcasing the Auralis Studio One wireless headphones. The page pairs a clean editorial layout with product details, pricing, customer reviews, and a product story to help shoppers explore the headphones and make a purchase decision.

## Product page description

Discover Studio One: wireless over-ear headphones designed for rich, considered sound and all-day comfort. Visitors can browse product photos, choose a color, adjust the quantity, and add headphones to a shopping bag. The page also highlights noise cancellation, included accessories, shipping and returns, and a 30-day listening promise.

## Features

- Responsive layout for desktop and mobile screens
- Product image gallery with accessible thumbnail controls
- Color selection and quantity controls
- Dynamic pricing and shopping bag feedback
- Expandable product, box contents, and shipping details
- Product story and customer review sections

## Technologies

- **HTML5** — page structure and product content (`index.html`)
- **CSS3** — responsive layout and visual styling (`product-page.css`)
- **Vanilla JavaScript** — gallery, quantity, color, and bag interactions (`product-page.js`)

## Project files

- `index.html` — product page markup
- `product-page.css` — responsive styling
- `product-page.js` — interactive behavior
- `styles.css` and `script.js` — duplicate stylesheet and script files retained in the repository

## Run locally

Open `index.html` in a browser. To serve it locally, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

Auralis is a fictional brand created for frontend portfolio practice. This demo simulates an e-commerce product page without a framework, backend, or real checkout.
